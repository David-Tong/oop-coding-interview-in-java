# 任务调度器

设计并使用 Java 实现一个任务调度系统。

团队中有不同的员工，每位员工拥有不同的技能。系统中有不同的任务，每项任务有一定的工作量，并需要具备相应技能的员工来完成。

调度器需要根据员工的技能分配任务，并尽可能让员工之间的工作量分配均衡。系统还应能够查询员工的当前工作量。

员工、任务和调度器如何建模，如何衡量工作量与均衡程度，采用什么调度策略，以及提供哪些接口，都由你自行设计。对于题目没有说明的情况，可以作出合理假设，并在实现中简要说明。

实现放在本题的 `solution/` 目录下。评审将结合你的设计假设和实际实现，考察系统是否满足上述业务目标、调度策略是否合理、对象职责与封装是否清晰，以及代码的正确性、可读性和测试质量。不会按预设的接口、算法或题目未约定的细节打分。

# 失败一致性测试

`Engine.execute()` 按顺序执行构造时传入的命令列表，遇到失败立即停止。此前成功的操作保留，失败操作的操作数恢复，撤销历史不变。

调用者捕获异常后，可以通过 `Engine.execute(Command)` 继续提交单个操作。再次调用无参 `execute()` 会从头重放原命令列表，不应将其作为失败后的继续执行入口。

`TestEngine` 通过公开 API 验证以下行为：

- 加法弹出一个操作数后因操作数不足失败，恢复原值；一次撤销即可回到空状态，证明失败没有增加或消耗历史。
- 二元命令在两个操作数都弹出后抛异常，原异常对象继续传播；后续减法验证两个操作数及顺序恢复，连续撤销验证早期历史保留。
- 批量执行失败后，通过单操作入口继续输入、计算和撤销。
- 空历史撤销失败后，仍能输入数字并正确撤销，也能再次输入。

运行作者测试：

```text
mvn -f simple-calculator/scores/9/pom.xml test
```

这些测试验证失败一致性，不代表严格输入和重复求值等其他契约已经通过验收。
